# Capturas del tutorial de Windows Server 2025

Los 9 archivos SVG son placeholders, no capturas reales. Se conserva la numeración de 02 a 10 tras retirar la primera imagen. La página funciona sin imágenes externas ni JavaScript.

## Cómo sustituirlos

1. Guarda tu captura en esta carpeta con el nombre PNG indicado abajo (también puedes usar WebP o JPG).
2. En `../index.html`, localiza el comentario de esa captura y cambia el `src` de `.svg` a `.png` (o a tu extensión).
3. Actualiza `alt` para describir la captura real y elimina «Captura pendiente». Ajusta `width` y `height` a las dimensiones reales para evitar saltos de diseño.
4. Revisa el pie de foto y abre la página. El CSS adapta la imagen al ancho disponible y conserva su proporción.

No captures contraseñas, claves ni datos del formulario de descarga. Mantén legibles los nombres de las opciones; recorta el escritorio del anfitrión si no aporta información.
