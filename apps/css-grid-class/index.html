Before you start

What is Grid used for?

CSS Grid is a two-dimensional layout system. It lets us control columns and rows at the same time. It is ideal for galleries, dashboards, card layouts, full pages and any interface whose elements need to line up precisely.

Grid vs Flexbox

Use Flexbox when you mainly need to arrange items in one direction. Use Grid when rows and columns matter at the same time. Real projects often use both.
