Before you start

What is Flexbox used for?

CSS Flexbox is a one-dimensional layout system. It distributes items along a main axis and aligns them along a cross axis. It is particularly useful for navigation bars, button groups, card rows, centring content and components whose size or spacing needs to adapt.

Flexbox vs Grid

Flexbox works best when the layout follows one main direction: a row or a column. Grid is usually the better choice when rows and columns must be controlled together.

Two roles: container and items

You apply display: flex to a parent—the flex container. Its direct children become flex items. Some properties belong to the container, such as justify-content; others belong to individual items, such as flex-grow.
