# Borja Molina Zea Personal Website

This repository contains a small personal website published with GitHub Pages.

## Courses

The site includes a `courses/` section for lecture notes powered by BorLectures. Each course lives in its own folder with a single `index.html` notes file and an optional local `assets/` folder for course-specific images or diagrams.

Current course placeholders:

- `courses/TIC1/`
- `courses/TIC2/`
- `courses/servicios-en-red-2smr/`

Course notes use the shared BorLectures viewer files from `COPY_PASTE_FOR_AGENTS.md`; the BorLectures viewer code is not copied into this repository.
